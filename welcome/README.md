# Лендинг Kseles-DreamBoards

Самостоятельная страница `welcome/`: знакомство с приложением, коллаж, возможности, переключение темы примера, анимация дыхания с паузой, установка и FAQ. Тексты: без подписки и рекламы, для вдохновения своей мечтой. Нет отзывов, вымышленных показателей популярности или обещаний исполнения желаний.

CTA ведут в `../index.html`, поэтому preview остаётся в preview, а основной сайт — в production. Публичных APK в GitHub Releases на момент проверки нет: вместо фиктивной ссылки скачивания показаны установка веб-приложения и запуск в браузере. Инструкции сверены с [Apple](https://support.apple.com/en-gb/guide/iphone/iphea86e5236/ios) и [Chrome](https://support.google.com/chrome/answer/9658361?co=GENIE.Platform%3DAndroid&hl=en-GB).

Фото взяты из существующих ассетов приложения. Иллюстрация доски — HTML/CSS, символ дыхания — SVG. Нет CDN, внешних шрифтов, аналитики, форм сбора данных или новых сервисов. JS обслуживает только переключение темы примера и паузу анимации, не меняет настройки приложения. Навигация и инструкции доступны без JS; учитывается prefers-reduced-motion.

Основная доска и её service worker не меняются. Лендинг не добавляется в офлайн-кэш приложения: его публикация не требует изменения сборки приложения. Проверка: Chromium 1440, 390, 320, отсутствие горизонтального переполнения, изображения, переключение темы, пауза, ссылки, переход в приложение, отключённые анимации и JS. Снимки и результаты в scratch/qa-landing.
