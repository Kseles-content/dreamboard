# Архитектура и данные

[К документации](../README.md) · Состояние на 2026-09-10.

## Публикуемое приложение

GitHub Pages публикует статические файлы из корня репозитория. HTML, CSS и JavaScript выполняются в браузере. `config.js` содержит публичные настройки: `authEnabled: false`, облачная авторизация выключена. Прежний прототип в `apps/` не обслуживает эту доску.

| Файлы | Назначение |
| --- | --- |
| `index.html`, `app.js` | Интерфейс и основные сценарии |
| `storage.js`, `backup.js`, `import.js` | Сохранение, резервные копии и импорт |
| `appearance.js`, `appearance.css` | Оформление |
| `image-library.js`, `png-export.js` | Изображения и экспорт |
| `manifest-breath.css` | Дыхание в приложении |
| `assets/audio/meditation-bell-01.mp3` | Выбранный звук 01 |
| `analytics.js` | Ограниченный сбор событий |
| `service-worker.js`, `sw-register.js`, `manifest.json` | PWA и кэш |
| `welcome/`, `about/` | Лендинг, баннер и информация |
| `infra/statistics/`, `infra/photo-search/` | Серверные сервисы |

## Хранение и сеть

localStorage: основная запись `dreamboard_app_state`, восстановительная — `dreamboard_app_state_recovery`, версия схемы 2. Локальные изображения используют IndexedDB `dreamboard-local-images`, версия 1. JSON-копия имеет `formatVersion: 1`.

Имена кэша изолированы по service-worker scope. В v29 ресурсы приложения используют `dreamboard-dreamboard-v29` и `dreamboard-dreamboard-v14-preview-v29`. Список `PRECACHE_URLS` включает выбранный MP3.

Фото Pexels при отображении через service worker загружаются с CORS и сохраняются в `dreamboard-<scope>-photos-v1`. Читаемые ответы используются и для отображения, и для PNG; этот кэш сохраняется при обновлении ресурсов приложения. Ошибки и непрозрачные ответы не сохраняются как пригодные для экспорта фото. Недоступность кэша не блокирует загрузку из сети.

Кэш может быть очищен браузером; это не постоянная резервная копия. Ссылки внешних фото в JSON по-прежнему остаются ссылками. После обновления старые доски нужно открыть с сетью для заполнения кэша. Не все внешние фото и рекламные страницы гарантированно доступны офлайн.

Поиск фото обращается к `https://kseles.ru/dreamboard-api/photos`; ключ поставщика находится на сервере. Подробности — в [инструкции поиска](../../infra/photo-search/README.md).

## Статистика

POST `https://kseles.ru/dreamboard-api/events` принимает только `event`, `source`, `environment` с фиксированными значениями, до 256 байт. События: `landing_view`, `app_open_click`, `app_open`, `install_help_open`, `appinstalled`, `standalone_open`, `png_ready`, `png_download_click`.

Сборщик не отправляет тексты целей, фото, email, cookies и постоянный идентификатор посетителя. Есть отключение через `dreamboard-statistics-disabled`, учёт DNT, таймаут 3 секунды и предел 3 одновременных запросов. Очереди повторов нет.

Сервер хранит суточные агрегаты UTC в SQLite 365 дней; публичного чтения отчёта нет. Nginx ограничивает частоту, процесс — потребление ресурсов. Origin не является аутентификацией: события можно подделать. Счётчики приблизительные, не равны уникальным людям и не подтверждают сохранение файла. Ограничения защиты и журналирования — в [инструкции статистики](../../infra/statistics/README.md).

## Дыхание и звук

Четыре фазы по 4 секунды: лендинг реализует их CSS-анимацией, приложение — планировщиком. При изменении длительности проверяйте оба места и `prefers-reduced-motion`.

Web Audio загружает и декодирует MP3; воспроизведение начинается на вдохе и выдохе, остановка плавно снижает громкость. Поздняя загрузка не должна включать звук после выключения или повторного старта. Эти сценарии покрывает `breath-audio.test.js`.
