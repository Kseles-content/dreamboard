# Подборки и форма создания мечты — 8 сентября 2026

Первый пакет согласованного плана. Ограничение пользователя: без платных сервисов и зависимости от регулярной активности.

Удалена имитация Unsplash-поиска, формировавшая адреса с 404. Вместо неё — честно названная подборка с поиском по русским названиям и тегам: восемь встроенных обложек и 24 существовавшие ранее ссылки на фотографии. Сетевые фотографии показываются только при выборе «Все подборки»; ошибки отключают выбор, повторный поиск повторяет загрузку. Это не поиск по всему интернету.

Шесть новых обложек — небольшие векторные иллюстрации, две — существующие изображения приложения. Все включены в офлайн-кэш; аккаунт, API и серверный обработчик не нужны. Внешние фотографии зависят от сети и доступности источника.

Изображение расположено сразу после названия мечты. Перед выбором можно рассмотреть обложку. Enter в поиске не отправляет форму. Смена категории меняет порядок предложений, сохраняя выбранное фото, включая ещё не сохранённую локальную загрузку. При новом открытии формы очищается прежний поисковый запрос и поле прямой ссылки.

Форма получила непрозрачный фон, контрастные поля и более компактные мобильные вкладки. Версия кэша — v18, build 2026-09-08-v18-image-library. Форматы основных данных и резервных копий не менялись; вход выключен.

Проверки: 289 Node tests; изолированный Chromium на 320×640, 390×844 и 1440×900. Проверены Enter без сохранения, выбор и сохранение после перезапуска, пустая выдача, отказ загрузки всех 24 внешних фотографий и сохранение локального фото при смене категории. Отдельный контекст с service worker: перезагрузка без сети, поиск, просмотр и выбор встроенной обложки. Реальное устройство с экранной клавиатурой требует пользовательской приёмки.

Следующий этап: полноценный поиск только после подтверждения доступного размещения без новых расходов и требований активности; темы и настройка доски могут разрабатываться независимо. API Pexels пока не подключён. Не заявляем гарантии будущих условий внешнего сервиса.

Этот пакет подготовлен поверх PR #42. Перед переносом в main проверить оба изменения и актуальные CI; старое подтверждение дыхательного режима не считать приёмкой новой формы.
