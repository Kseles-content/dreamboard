# Экспорт плаката PNG

Кнопка скачивания изображения открывает диалог: экранный PNG, вертикальный А2 150 dpi (2480×3508), А2 300 dpi (4961×7016). Перед скачиванием показывается результат. Подпись Kseles-DreamBoards впечатывается в пиксели справа снизу на отдельном поле, с отступом от края. Для печатных файлов записывается корректный pHYs с плотностью печати.

Экспортируется текущая категория активных целей, с темой, подробностями и выбранным заполнением фото. Сетка собирается для изображения независимо от ширины телефона; обычный печатный вариант использует две колонки. Свободный холст сохраняет относительные координаты и размеры карточек, обрезая внешнюю пустоту. Кнопки управления не экспортируются. Подписи авторов Pexels остаются в карточках.

Файл создаётся локально через Canvas без сервера, платных сервисов или новых зависимостей. Фотографии из IndexedDB читаются напрямую; сетевые загружаются CORS-запросами без credentials. CSP разрешает чтение только уже используемых фотодоменов. Отказ, CORS, отсутствие сети или лимит времени дают видимую заглушку и предупреждение до скачивания. Настройки и данные доски не изменяются.

Ограничения: максимум 100 целей за раз; экран до 4096 пикселей по стороне/12 Мп; фотографии загружаются последовательно, одна загрузка ограничена временем и размером 25 МБ. Для чрезмерно разнесённого холста предлагается категория или сближение карточек. А2 300 dpi требует существенно больше памяти, рекомендован компьютер. Увеличение числа пикселей не добавляет деталей исходным фотографиям. Холст сохраняет ограниченную высоту карточек; для полного текста удобнее сетка. Это RGB PNG без типографских вылетов, при печати выбирается бумага А2 42×59,4 см.

Проверки: 306 Node tests; реальные PNG из Chromium с проверкой размера и dpi через Pillow; темы, экран/А2/А2 HQ, свободный холст, локальные фото, недоступные изображения, пустая подборка, сохранность данных и доступность модуля офлайн. Для локальных визуальных проверок внешние фотографии заменены локальным изображением. Отдельная проверка опубликованного сайта использует настоящую сеть.
